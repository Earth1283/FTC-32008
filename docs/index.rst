FTC 32008 documentation
=======================

Welcome to the FTC 32008 code documentation.

As you may or may not have noticed, our `TeamCode` is structured slightly differently from what you'd expect from a regular FTC team, and I'm sad to say that this is a feature, not a bug.

We aim to create documentation so as to:

1. Reduce the difficulty for new team members who'd wish to contribute to understand the code
2. Lower the barrier-to-entry to writing and understanding clean, well-designed code like ours.

How this differs from the engineering notebook
----------------------------------------------
The engineering notebook has to also feature the mechanisms on the robot. This document has no such obligation. We will focus exclusively on the code.
